# Rust Survival

**Rust Survival** — це хардкорний модпак для Luanti (Minetest), який переносить культові механіки гри Rust у блоковий світ. 

Грайте з друзями або на публічному сервері: будуйте бази, захищайте їх від рейдів, крафтіть вибухівку та боріться за виживання. Пам'ятайте: коли ви вмираєте, ви втрачаєте **все**.

## Головні особливості

*   **100% Втрата інвентаря:** При смерті всі ваші речі падають на землю.
*   **Випадковий респавн:** Ви прокидаєтесь голими на випадковому пляжі, далеко від місця смерті.
*   **Будівництво та Рейди:** 4 тіри блоків (від дерева до броні), Сатчелі, C4 та міни.
*   **Tool Cupboard (TC):** Шафа, яка захищає вашу базу та авторизує друзів. 
*   **Утримання (Upkeep):** Бази гниють, якщо ви не закидаєте в TC ресурси (камінь, сталь, діаманти).
*   **Вікно рейдів (Raid Window):** Вибухівка працює лише вночі (за замовчуванням з 19:00 до 07:00).
*   **Вайпи:** Раз на тиждень (або вручну) всі бази знищуються, а світ починається з нуля.

## Встановлення

1. Завантажте папку `rust_survival` та покладіть її в директорію `mods/` вашого Luanti.
2. Запустіть гру та створіть новий світ на базі `Lean Core` (або Minetest Game).
3. У налаштуваннях світу (Configure) знайдіть мод **rust_survival** (мета-мод) і поставте галочку. Всі 6 модулів підтягнуться автоматично.
4. **ВАЖЛИВО:** У налаштуваннях світу увімкніть `Enable Damage` (шкода), інакше хардкор не працюватиме. Також рекомендується вимкнути стандартний мод `bones`, щоб уникнути конфліктів зі смертю.

## Як грати (Швидкий старт)

1. **Знайдіть ресурси:** Добудьте дерево, камінь та залізо.
2. **Знайдіть безпечне місце:** Подалі від спавну.
3. **Скрафтіть Tool Cupboard (TC):** 20 дерева, 10 каменю, 4 сталі. Поставте його — це серце вашої бази.
4. **Задепонуйте ресурси:** Клікніть по TC правою кнопкою миші та покладіть ресурси в слот `Deposit Fuel`. Це запустить таймер утримання бази.
5. **Будуйте стіни:** Використовуйте блоки `rust_building:*`. Вони мають власне HP.
6. **Авторизуйте друзів:** `/rust_tc_auth <нікнейм>`.
7. **Рейд:** Скрафтіть C4 (потрібен порох, сталь та діамант). Пам'ятайте, що вибухати можна тільки вночі!

## Основні команди

| Команда | Опис |
|---|---|
| `/rust_tc_info` | Інформація про TC (радіус, HP, залишок утримання) |
| `/rust_tc_auth <гравець>` | Дозволити другу користуватися базою |
| `/rust_tc_unauth <гравець>` | Забрати доступ |
| `/rust_raid_status` | Перевірити, чи відкрито вікно для рейдів |

## Команди для адміністраторів

| Команда | Опис |
|---|---|
| `/rust_wipe confirm` | М'який вайп (знищити всі бази та інвентарі) |
| `/rust_wipe_status` | Перевірити статус автовайпу |
| `/rust_tc_admin list` | Список усіх баз на сервері |

## Налаштування (minetest.conf)

Рекомендовані параметри для хардкорного сервера:
* `rust_core_use_real_time = true` (прив'язка часу рейдів до реального життя)
* `rust_core_utc_offset = 2` (часовий пояс для України, зима)
* `rust_wipe_auto_enabled = true` (увімкнути автоматичний вайп раз на тиждень)
* `rust_tc_upkeep_enabled = true` (бази гниють без ресурсів)
